# Scene concept

Preserve the requested location, architecture, time, weather, era, and core layout. Improve spatial
hierarchy through foreground/midground/background separation, leading geometry, scale cues, motivated
light, atmospheric depth, controlled palette, and a clear visual anchor.

Do not add characters, vehicles, signage, props, weather, or narrative events unless requested. For an
edit, retain camera position, perspective, major architecture, door/window placement, and scene layout
unless the user explicitly changes them.
