# Seedance

Use the capability registry as authority. The notes below are operator field observations, not capability
claims - the registry overrules any of them for a specific version.

## Registered version

Seedance 2.5 (`doubao-seedance-2-5-260628`) on the Ark transport, 1-15s, up to 4 reference images, 720p or
1080p. It is the `VIDEO_SEEDANCE` primary on both the FREE and paid tiers, so it is the version these notes
describe unless the registry says otherwise.

## Where it is strong

- Bright, well-lit shots. This is the preferred option when the frame is high-key and the subject is clearly
  separated from the background.
- Chronological blocking, temporal control, multi-character relationships, Chinese context.

## Known failure modes

- **Compressed long narrative.** As with Wan, several beats compressed into one shot produce disjointed or
  fragmented characters. Longer accepted durations do not change this; decompose the shot.

## How to prompt it

- One dominant action, even when the version accepts longer durations or several references.
- Name reference roles explicitly: identity, scene, product, start state or motion.
- State camera movement as one path with a start, a speed and an end, rather than several movement labels.
- Preserve dialogue and lip-sync requirements only when the selected version supports them.

## Check the output for

Narrative compression, character splitting, conflicting references, drift during long actions.
