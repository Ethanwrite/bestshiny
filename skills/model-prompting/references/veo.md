# Veo

Use the capability registry as authority. The notes below are operator field observations, not capability
claims - the registry overrules any of them for a specific version.

## Where it is strong

- Detailed comprehension of the described frame. It reliably converts explicit spatial description into
  what is actually rendered, so subject placement and movement trajectories are worth stating precisely.
- Stable on character positioning and trajectory cues relative to the alternatives, which makes it the
  preferred choice for a transient or transitional scene that has to land on the first attempt.
- Supports extension when the selected version declares it. Confirm in the registry before relying on it.

## How to prompt it

- Concise spatial language, motivated lighting, material response, continuous action, premium finish.
- State subject position, camera path, audio and dialogue intent, and end composition without stacking
  adjectives. Adjective stacking displaces the spatial description this model actually uses well.
- Preserve exact product geometry, labels and reflection behaviour through explicit invariants.
- Request native audio, reference images or end-frame controls only when the exact version supports them.

## Check the output for

Invented narrative beats, excessive camera choreography, unreadable product text, audio conflicts.
